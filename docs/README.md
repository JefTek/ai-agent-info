# Project tracking

Documents that track the state of this repository rather than instructing an
agent. Guidance for agents lives in [claude-ai](../claude-ai/README.md),
[copilot](../copilot/README.md), and [shared](../shared/README.md).

## Contents

- [Changelog](CHANGELOG.md) — notable changes, grouped by date.
- [Roadmap](ROADMAP.md) — candidate work, and what is deliberately not
  planned.
- [Known issues](ISSUES.md) — open problems and accepted limitations.

Use [GitHub Issues](https://github.com/JefTek/ai-agent-info/issues) for
anything needing discussion, assignment, or a due date. `ISSUES.md` carries
only what a reader of the repository should know without leaving it.
